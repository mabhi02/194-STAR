Book Query Examples

Examples of SQL queries using the books database:

  1. SELECT title, price, publication_year FROM books WHERE price > 50;
  2. SELECT b.title, bo.order_date, bo.quantity FROM book_orders AS bo JOIN books AS b ON bo.book_id = b.id;
  3. SELECT b.title, bo.order_date, bo.quantity FROM book_orders bo JOIN books b ON bo.book_id = b.id WHERE b.price > 40;
  4. SELECT b.genre, SUM(bo.quantity) FROM books b JOIN book_orders bo ON b.id = bo.book_id GROUP BY b.genre ORDER BY SUM(bo.quantity) DESC;
