You are working with a database that contains information about customers, orders, books, and book orders. The database has four tables:

  • customers: Contains customer information including ID, name, and email
  • orders: Contains order information including ID, customer ID, amount, and order date
  • books: Contains book information including ID, title, price, publication year, and author ID
  • book_orders: Contains book order information including ID, book ID, quantity, and order date

Use the SQL Builder below to answer the following questions:

Question 1: Find all customers who have placed orders with a total amount greater than $100.

Question 2: Find the title, price, and publication year for all books with a price between 20 and 50 inclusive.

Question 3: Find the title, order date, and quantity for all book orders where the book price is greater than 40.

The correct answers are:

-- Question 1 SELECT c.name, c.email, SUM(o.amount) as total_amount FROM customers c JOIN orders o ON c.id = o.customer_id GROUP BY c.id, c.name, c.email HAVING SUM(o.amount) > 100; -- Question 2 SELECT title, price, publication_year FROM books WHERE price BETWEEN 20 AND 50; -- Question 3 SELECT b.title, bo.order_date, bo.quantity FROM book_orders bo JOIN books b ON bo.book_id = b.id WHERE b.price > 40;
